          Browser add-on for website names

          BeaconMap can only see which company owns a server. Your browser knows which website it was for. This optional add-on passes that on, so a row like “chrome → Amazon AWS” also shows the site names.

          What it sees: the name of each website your browser loads, and the server address. Where it goes: only to BeaconMap on this computer. It never reads page contents, full links, passwords or history, and it is two short files you can read.
